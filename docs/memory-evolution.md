# 固定权重的记忆 harness 演化

当前优先级是先验证可重复的 harness 收益；LoRA、RL 与权重更新均后置。以下协议在正式搜索前固定，结果无论正负都保留。

## 任务和数据

参考 [Meta-Harness](https://arxiv.org/html/2603.28052v1) 的记忆分类实验，只复用公开数据，独立实现执行与演化代码。Task 为固定快照 Qwen3-4B-Instruct-2507，Meta 为项目隔离的 Claude Code + DeepSeek。该小模型实验不宣称复现论文主表。

公开数据原为 train200 / val50 / test212。按规范化题目精确去重，发现 test140 与 val27 重复，排除该测试题后为 **200 / 50 / 211**。下载脚本固定 Git blob SHA，记录原始/转换后哈希、排除ID与规则，不运行第三方代码。

训练记忆为唯一可检索的带标签数据。Meta获得训练内32题leave-one-out诊断（剔除当前题自身），以及候选的验证汇总；不获得逐题验证内容或任何测试反馈。标签集合、输出约定、评分、模型、数据、上下文及调用上限由宿主固定。

## 可演化范围与对照

`MemoryPolicy` 支持 BM25、TF-IDF、词/字符混合检索；示例数量、标签多样性/数量上限、示例顺序、检索建议；直接分类、草稿验证或查询改写。它改变实际取用的记忆和执行步骤，最多每题两次模型调用。当前是结构化策略空间，不执行任意生成代码。

固定对照包括 no-memory、固定8条few-shot、BM25-8、BM25-8加固定验证。以三次验证准确率最高者作为父代，同分时优先较少调用/token。随机配置搜索使用相同候选数、重复次数和单题上限；实际调用数、token和耗时单独报告，不假定其实际成本相等。

## 搜索与稳定性门槛

- 三次独立搜索，种子42、123、2026控制训练记忆顺序、诊断采样及随机对照；Meta CLI的采样不能由该种子完全控制。
- 每次5轮，每轮Meta给出2个不同候选；每候选验证重复3次。全部非法、退步和平局候选保留。
- 接受需每次重复均不退步，平均至少多答对1道验证题；两个候选中择优。不将开发分的单调性视为泛化证据。
- 同预算随机配置搜索同样5轮×2候选；Static始终保留。
- 三次搜索与随机对照全部冻结后，才解封最终测试。对父代、选中策略、随机对照及历史选中策略各重复测试3次；相同策略复用同一次评估。
- 当前稳定性门槛：三次独立搜索在测试上均超过各自的强固定父代，且先对同题的重复/搜索求平均、再按题配对bootstrap的95%区间下界大于0。此门槛仅针对固定模型和该任务；不表示跨任务泛化。
- 格式修正、换模型和加预算均不计为演化增益；不根据最终测试修改本轮策略或追加搜索。

## 运行

```sh
sh scripts/setup.sh
sh scripts/setup_task.sh
.venv/bin/python scripts/prepare_memory_data.py
RSI_GPU=0 sh scripts/serve_task.sh
```

另一个终端运行：

```sh
.venv/bin/python scripts/run_memory.py suite --output runs/memory-s2d-suite-v4
.venv/bin/python scripts/run_memory.py finalize --output runs/memory-s2d-suite-v4
```

当前配置 `configs/memory_s2d.json`；Task每次输出128token、temperature0，记忆上下文12000字符、单题至多两次调用。搜索中断后同命令恢复，源代码/依赖/输入变化则拒绝恢复。正式搜索时不修改实现。凭据仍为忽略的`.env.local`，本地无鉴权Task端点使用`EMPTY`。

## 第三组：使提案过程更稳定

v4与v3保持相同固定参考父代、任务模型、评分和单题预算，用于比较提案策略；不会把重启实验算成继续突破历史最优。每轮改为一个通用局部结构邻居和一个Meta候选，共仍为两个候选。局部邻居仅按配置数值做有界相邻变更，不使用类别、题目或答案常量。这是算法开发阶段基于训练/验证的调整，最终测试仍未用于设计。

同时补齐每一步预测和记忆顺序；同一训练记忆在Meta输入中只传一次。无效的未启用参数会规范化，防止相同执行被当作新策略重评。Meta输出溢出会被拒绝，混合策略仍可评估合法的局部候选。随机对照的整数参数改为在完整合法范围均匀采样；v2/v3历史随机对照使用粗网格，需区分其采样分布。

上述为一组工程调整，不能把全部收益单独归因于某一个改动。v4仍按原定三次搜索、三次重复和独立测试门槛验收；LoRA继续后置。
