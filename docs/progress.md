## 状态用语

- 设计完成：已形成可审阅的协议/方案。
- 已实现：存在对应可执行代码。
- CPU 验证：在无 GPU 环境中通过明确检查。
- GPU推理验证：真实本地模型服务与执行通过；不表示权重更新。
- GPU训练验证：真实权重更新、导出、重载与执行通过。
- Benchmark 验证：固定协议下与任务评分器一致。
- 已同步：远端接受提交并核对 SHA。

只有达到相应证据层级才更新状态。
